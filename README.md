An ultra-modern, high-performance personal portfolio website built with modern web standards, highlighting professional industry experience at **Azeosoft Web Technologies Pvt. Ltd.**, verified full-stack applications, modern component architecture, and direct contact channels.

## ✨ Features & Highlights

- 💼 **Professional Experience Showcase**: Detailed work history at **Azeosoft Web Technologies Pvt. Ltd.** (Full Stack Developer Intern), detailing enterprise projects including **Tracker 29** (Employee Activity Monitoring), **D2C Seller Panel / DirectToCart**, and **WebJF**.
- 🛠️ **Real-World Projects with Live Search**: Search projects in real-time by keyword (`Next.js`, `TypeScript`, `Zod`, `REST`) or category with genuine live deployments (`GEN-JI`, `SkillSwipe`, `School Management Portal`, `Aimhop Edu Trust`, `Spotify Clone`, etc.) and verified GitHub source links with **zero broken or placeholder links**.
- 📄 **Instant Resume Preview Modal**: Embedded glassmorphic PDF viewer allowing recruiters to inspect `resume.pdf` without downloading, with 1-click download and new-tab options.
- 🏗️ **System Architecture & Deep Dive Modals**: Interactive engineering breakdowns for major projects (D2C Seller Panel, GEN-JI) detailing UI layers, Zod validation engines, REST APIs, and architectural tradeoffs.
- 💻 **Live Code Playground**: Tabbed interactive code showcase with production-grade TypeScript snippets (Zod validation, resilient API client with retries, BFS level-order traversal).
- ⚡ **15-Second Recruiter Brief**: Quick decision summary card with core capabilities, experience metrics, and quick hiring actions.
- 🔗 **1-Click Share Portfolio Modal**: One-click URL copying with LinkedIn and WhatsApp sharing integration.
- 🎨 **Modern Design & UI Tokens**: Glassmorphic cards, ambient gradient glow, tailored typography (`Plus Jakarta Sans` & `JetBrains Mono`), and high-contrast color palettes.
- 🌓 **Dynamic Dark / Light Theme**: Instant theme switching with system preference detection and `localStorage` persistence.
- 📱 **100% Responsive Layout**: Fluid mobile navigation drawer with animated hamburger toggle and optimized desktop experience from 320px to 1440px+.
- ✉️ **Direct Email Delivery**: FormSubmit AJAX direct delivery to `dy516824@gmail.com` with animated success banner and fallback client support.
